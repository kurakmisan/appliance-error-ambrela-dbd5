A one-line honest appliance error from a microwave: it beeps when done, yet the food is hot at the edges and frozen in the middle — the most common microwave truth there is. `main.py` writes that single line (98 characters) to `/output/entry.txt`. Standard library only, no input, no network, same bytes on every run.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
APPLIANCE_OUTPUT_DIR=./out python3 main.py   # or write ./out/entry.txt
```
